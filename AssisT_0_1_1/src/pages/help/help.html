AssisT Help & Documentation

Adaptive Learning Technology for Students

Getting Started

AssisT is an adaptive educational technology extension designed to support neurodivergent students and learners with diverse needs. Click the extension icon in your browser toolbar to open the control panel and customize your experience.

Key Features

Reading Help

  • Text-to-Speech (TTS): Listen to any text on the page with synchronized highlighting
  • Reading Mode: Distraction-free reading environment with customizable settings
  • Dyslexia Support: Bionic reading, syllable colors, and grammar highlighting modes
  • OCR (Image Reading): Extract and read text from images
  • Speed Reading (RSVP): Rapid serial visual presentation for faster reading

Writing Help

  • Speech-to-Text (STT): Voice input with auto-punctuation and voice commands
  • Annotations: Create sticky notes and highlights with organization tools
  • Citations: Manage sources and generate citations

Page Customization

  • Text Customization: Adjust font, spacing, and sizing for optimal readability
  • Focus Mode: Spotlight specific areas while dimming distractions
  • Reading Guide: Visual ruler to track reading position
  • Dark Mode: Reduce eye strain with dark theme

AI-Powered Tools

  • Text Summarization: Get concise summaries of complex content
  • Text Simplification: Convert complex text to simpler language
  • Socratic Tutor: Guided questions to deepen understanding
  • Assignment Breakdown: Break complex assignments into manageable steps

Tips for Best Experience

  • Start by taking the Discovery Quiz to get personalized feature recommendations
  • Use the Organize button to customize which features appear in your popup
  • Enable features one at a time to learn how each works
  • Try different TTS voices and speeds to find what works best for you
  • Use the Highlight Menu (appears when you select text) for quick access to common actions
  • Experiment with text customization settings to reduce eye strain

Privacy & Data

AssisT respects your privacy:

  • All settings and data are stored locally on your device
  • No personal information is collected or transmitted
  • AI features (when enabled) process data locally or through your chosen provider
  • You can export/import your settings for backup or transfer

Troubleshooting

Features Not Working?

  • Make sure the feature is enabled in the popup panel
  • Try refreshing the page after enabling a feature
  • Check browser permissions if using microphone or camera features
  • Use the Reset button in Settings if something seems broken

Performance Issues?

  • Disable unused features to reduce resource usage
  • Clear browser cache if pages load slowly
  • Reduce animation effects by enabling "Reduced Motion"
