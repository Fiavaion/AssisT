ND-Ready Accessibility Threshold

The Neurodivergent-Ready (ND-Ready) threshold determines whether model output is safe and effective for students with learning difficulties. Passing requires:

  • ✅ Weighted score meets feature-specific minimum (typically 7.0-8.0+)
  • ✅ No critical issues flagged by the evaluator
  • ✅ "recommended" flag set to true by Opus judge
