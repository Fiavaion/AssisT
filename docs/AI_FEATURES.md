# AssisT LLM Edition - Local AI Features

## Overview

AssisT LLM Edition adds local AI capabilities through Ollama. All processing happens on your machine - no data is sent externally.

**Requirements:** Ollama with `llama3.2:3b` and `llava` models

---

## AI Features

### 1. Smart Summarization
Condense long texts into brief, detailed, or bullet-point summaries. Includes ELI5 mode for simplified explanations.

### 2. Text Simplification
Rewrite complex text in simpler language at moderate, simple, or very simple levels while preserving meaning.

### 3. Assignment Breakdown
Transform assignment instructions into step-by-step task lists with time estimates and priority indicators.

### 4. Socratic Tutor
Generate thought-provoking questions (comprehension, analysis, synthesis, evaluation) to deepen understanding.

### 5. Emotional TTS
Detect emotional tone in text and adjust speech rate, pitch, and volume for more natural reading.

### 6. Image Understanding
Generate AI descriptions of images using the LLaVA vision model. Supports brief, detailed, and comprehensive descriptions.

### 7. Cognitive Profile
Learn user preferences over time to personalize AI responses. All data stored locally.

### 8. Citation Analyzer
Analyze sources and citations for credibility, bias, and reliability. Provides:
- Source type classification (academic, news, blog, etc.)
- Credibility scoring (0-100)
- Bias detection and severity rating
- Key claims extraction
- Strengths and weaknesses analysis
- Recommendations for source use

### 9. Knowledge Graph
Visualize connections between concepts, annotations, and citations in an interactive graph.

### 10. Adaptive RSVP
Speed reading with Rapid Serial Visual Presentation, adapting pace based on word complexity.

### 11. Struggle Detection
Detect when users are struggling and proactively offer assistance.
