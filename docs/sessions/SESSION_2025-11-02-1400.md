## Important Context

### Recent Decisions
- **DEC-202511-001**: Adopt Hybrid Architecture for STT Module (already in PROJECT_MEMORY.md)
  - Foundation in orchestrator (thin coordination layer)
  - Implementations in modules (complex engine logic)
  - Proven pattern from TTS architecture

### Key Insights Discovered
- **WebSpeechEngine Integration Pattern Works:**
  - Dynamic import with `await import()` allows lazy loading
  - Callback-based architecture keeps orchestrator simple
  - Post-processing can be done in orchestrator (simple logic) or modules (complex logic)

- **Text Insertion Must Handle Multiple Element Types:**
  - `<input>` and `<textarea>`: Use `.value` property + selection API
  - `contenteditable`: Use DOM Range API + Selection API
  - Both need to trigger `input` event for React/Vue compatibility

- **Voice Command Processing:**
  - Basic punctuation commands work well ("period", "comma", "question mark")
  - Auto-capitalization after sentence-ending punctuation
  - Final results get processed, interim results pass through unchanged

### Risks/Warnings
- ⚠️ **ONNX Runtime Web compatibility not yet validated** - Before Phase 2, create proof-of-concept to test Vite bundling with ONNX Runtime Web
- ⚠️ **WebGPU availability varies by browser** - Need fallback to WASM backend for older devices
- ⚠️ **Model size may be large** - Whisper base model ~140MB, need IndexedDB caching strategy
