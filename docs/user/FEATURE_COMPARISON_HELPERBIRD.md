# Feature Comparison: AssisT vs Helperbird

This document compares AssisT with Helperbird, a popular accessibility browser extension, to help users understand the unique value proposition and feature coverage of AssisT.

---

## Overview

| Aspect | AssisT | Helperbird |
|--------|--------|------------|
| **Target Audience** | Neurodivergent students using Canvas VLE | General accessibility users |
| **Pricing** | Free, open source | Freemium ($6.99/month Pro) |
| **Platform** | Chrome Extension (Manifest V3) | Chrome, Edge, Safari, Firefox |
| **Privacy** | FERPA-compliant, no data collection | Data collection for analytics |
| **Offline Support** | Whisper.cpp local processing | Cloud-dependent |
