# 🚀 AssisT Quick Start Guide

**Get started with AssisT in under 5 minutes!**

---

## 📥 Installation

### Step 1: Install the Extension

1. Download or clone the AssisT repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable **"Developer mode"** (toggle in top-right corner)
4. Click **"Load unpacked"**
5. Select the **`Output`** folder from the AssisT directory
6. ✅ Done! The AssisT icon should appear in your Chrome toolbar

---

## 🎯 First-Time Setup (30 seconds)

### Enable Text-to-Speech

1. Click the **AssisT icon** in your Chrome toolbar
2. Toggle **"Enable TTS"** switch to ON (turns blue)
3. Select a **voice** from the dropdown (try different voices!)
4. Adjust **speed** to your preference (0.5x - 2.0x)

**✅ You're ready to read!**

---

## 📖 Reading Web Pages

### Method 1: Select and Read

1. **Select any text** on a webpage
2. **Right-click** on the selected text
3. Choose **"Read selection with AssisT"** from the context menu
4. 🎧 Text will be read aloud with word-by-word highlighting

### Method 2: Read Entire Page

1. Click the **"Read Page"** button in the popup
2. AssisT will read all text content on the page
3. Use **Play/Pause** button to control playback

### Playback Controls

- **Pause/Resume:** Click the pause button or press `Ctrl+Shift+P`
- **Stop:** Click the stop button
- **Adjust speed:** Use the speed slider in the popup

## 🎓 Using LMS Integrations (Canvas, Moodle, Google Classroom)

### Enable LMS Integration

1. Click the **AssisT icon** in your Chrome toolbar
2. Click the **⚙️ Options** button (gear icon)
3. Go to the **"Features"** tab
4. Scroll to **🎓 LMS Integration** section
5. Enable your platform:
   - ☑️ **Canvas LMS**
   - ☑️ **Moodle LMS**
   - ☑️ **Google Classroom**
6. Click **"Save Changes"**

### Reading LMS Content

Once enabled, navigate to your LMS:

**Canvas:**

- Open any assignment, discussion, or course page
- Look for the **purple FAB button** (📖) in the bottom-right corner
- Click it to read the content aloud

**Moodle:**

- Open any assignment, forum, or page resource
- Look for the **orange/gold FAB button** (📖) in the bottom-right corner
- Click it to read the content aloud

**Google Classroom:**

- Open any assignment, stream post, or classwork item
- Look for the **blue/green FAB button** (📖) in the bottom-right corner
- Click it to read the content aloud

## ✨ Dyslexia-Friendly Reading

### Enable Dyslexia Mode

1. Open the **AssisT popup**
2. Scroll to the **"Dyslexia Mode"** section
3. Toggle **"Enable Dyslexia Mode"** to ON
4. Choose your preferred mode:
   - **Bionic Reading:** Bold first letters of words for faster scanning
   - **Syllable Highlighting:** Alternating colors separate syllables
   - **Grammar Colors:** Color-code parts of speech (nouns, verbs, etc.)
5. Adjust **color intensity** with the slider

**💡 Tip:** Try different modes to find what works best for you!

## 🎨 Customizing Text Appearance

### Font and Spacing

1. Click **⚙️ Options** → **"Text Customization"** tab
2. Adjust:
   - **Font:** OpenDyslexic, Arial, Verdana, Comic Sans MS
   - **Font Size:** 12px - 32px
   - **Line Height:** 1.0 - 3.0 (WCAG recommends 1.5+)
   - **Letter Spacing:** 0% - 50% (WCAG recommends 12%+)
   - **Word Spacing:** 0% - 50% (WCAG recommends 16%+)
3. Click **"Save Changes"**

### Screen Overlays (Reduce Eye Strain)

1. Scroll to the **"Screen Color Overlay"** section in the popup
2. Toggle **"Enable Screen Overlay"** to ON
3. Choose a filter:
   - **Sepia:** Warm, book-like tone
   - **Blue Light Filter:** Reduces blue light for evening reading
   - **Grayscale:** High-contrast black and white
   - **Green Tint:** Calming green overlay
4. Adjust **opacity** (20% - 80%)

## 👤 Using Profiles (Quick Context Switching)

### What are Profiles?

Profiles save all your settings (voice, speed, font, dyslexia mode, etc.) for quick switching between different contexts.

### Default Profiles

AssisT includes 4 pre-configured profiles:

1. **Default:** Balanced settings for general use
2. **Reading:** Slower speed, larger font, dyslexia mode enabled
3. **Quiz:** Medium speed, focus mode, quiz helper enabled
4. **Low Vision:** Extra-large font, high contrast, slower speed

### Switching Profiles

1. Open the **AssisT popup**
2. At the top, click the **profile dropdown** (👤 Profile)
3. Select a profile
4. ✅ All settings change instantly!

### Creating Custom Profiles

1. Adjust all settings to your preference
2. Click **"Save Profile"** button
3. Enter a name (e.g., "Math Class", "Evening Reading")
4. Click **Save**

### Exporting/Importing Profiles

**Export:**

1. Click **⚙️ Options** → **"Profiles"** tab
2. Click **"Export Current Profile"**
3. Save the `.json` file

**Import:**

1. Click **⚙️ Options** → **"Profiles"** tab
2. Click **"Import Profile"**
3. Select your `.json` file
4. Profile is added to your list!

## 🔍 Focus Mode & Reading Guide

### Focus Mode

- **What it does:** Dims everything except the current paragraph
- **Enable:** Toggle "Focus Mode" in the popup
- **Use case:** Reduces visual distractions for ADHD

### Reading Guide

- **What it does:** Horizontal line follows your cursor/reading position
- **Enable:** Toggle "Reading Guide" in the popup
- **Customize:** Adjust color, thickness, and opacity in Advanced Options

## ⚙️ Hiding/Showing Features

### Simplify the Interface

Don't need Speech-to-Text or Screen Overlays? Hide them!

1. Click **⚙️ Options** → **"Features"** tab
2. Uncheck features you don't use:
   - Text Highlighting
   - Speed Presets
   - Text Customization
   - Reading Guide
   - Dyslexia Mode
   - Focus Mode
   - Screen Color Overlay
   - Speech-to-Text
   - LMS Integrations
3. Click **"Save Changes"**
4. ✅ Popup now shows only what you need!

**💡 Note:** Core TTS controls (voice, speed, pitch, volume) are always visible.

## 🎤 Speech-to-Text (Experimental)

### Enable STT

1. Click **⚙️ Options** → **"Features"** tab
2. Enable **"Speech-to-Text"** under ✍️ Writing Features
3. Click **"Save Changes"**
4. STT section now appears in the popup

### Using STT

1. Click in any **text field** on a webpage
2. Click the **🎤 microphone button** that appears
3. Start speaking
4. Say **"period"**, **"comma"**, **"question mark"** for punctuation
5. Click **🛑 Stop** when done
6. ✅ Text appears in the field!

**Voice Commands:**

- "period" → .
- "comma" → ,
- "question mark" → ?
- "exclamation point" → !
- "new line" → (line break)

## 🆘 Getting Help

### Help Button

Click the **❓ Help** button in the popup header to open the documentation.

### Common Issues

**TTS not working?**

- Ensure TTS is enabled (toggle at top of popup)
- Check that a voice is selected
- Try refreshing the page

**No FAB button on LMS pages?**

- Verify LMS integration is enabled in Advanced Options → Features
- Check that you're on a supported page type (assignment, forum, etc.)
- Refresh the page after enabling

**Settings not saving?**

- Check that you clicked "Save Changes" in Advanced Options
- Try reloading the extension (chrome://extensions/ → Reload)
