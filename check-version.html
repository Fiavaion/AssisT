Step 3: Force Reload Instructions

Option 1: Hard Refresh (Recommended)

  1. Close ALL Chrome windows completely
  2. Reopen Chrome
  3. Go to: chrome://extensions
  4. Find AssisT in the list
  5. Click REMOVE (trash icon)
  6. Click "Load unpacked"
  7. Select folder: C:\Users\jones\AIprojects\AssitT
  8. Refresh this page: Ctrl + Shift + R

Option 2: Clear Extension Cache

  1. Go to: chrome://extensions
  2. Enable "Developer mode" (top right toggle)
  3. Find AssisT → Click "Reload" button
  4. Clear browser cache:
  5. Press Ctrl + Shift + Delete
  6. Select "Cached images and files"
  7. Click "Clear data"
  8. Refresh this page: Ctrl + Shift + R

Option 3: Load from Different Location

  1. Copy the entire AssitT folder to a new location (e.g., Desktop)
  2. Remove the old extension from Chrome
  3. Load unpacked from the NEW location
  4. This forces Chrome to treat it as a completely new extension
