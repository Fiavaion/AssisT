## 🚀 INSTALLATION STEPS

### Step 1: Transfer Project Files

**Option A: Git Clone (Recommended)**
```bash
git clone <repository-url> AssisT
cd AssisT
```

**Option B: Copy Project Folder**
- Copy entire `AssisT/` directory to new PC
- Place in desired location (e.g., `C:\Users\YourName\Projects\AssisT`)

### Step 2: Install Dependencies

Open terminal in project root and run:

```bash
npm install
```

This will install all dependencies listed in `package.json`:
- **Production Dependencies**: Tesseract.js, PDF.js, D3, Dexie, Sortable.js, etc.
- **Dev Dependencies**: Vite, ESLint, Prettier, Jest, Playwright, Husky, etc.

**Expected Output:**
```
added XXX packages in XX.XXs
```

**⚠️ Common Issues:**
- **Error: EACCES**: Run terminal as administrator (Windows)
- **Network errors**: Check firewall/proxy settings
- **Peer dependency warnings**: Usually safe to ignore

### Step 3: Build the Extension

```bash
npm run build
```

This will:
1. Run Vite bundler to compile source code
2. Copy assets to `.vite/` directory
3. Inject popup scripts
4. Generate final extension in `.vite/`

**Expected Output:**
```
vite v7.1.12 building for production...
✓ built in XXXms
```

**⚠️ Critical Rule:**
- **ALWAYS edit files in `src/` directory**
- **NEVER edit files in `.vite/` directory** (auto-generated)
- **ALWAYS run `npm run build` after changes**
- Chrome loads the extension from `.vite/` directory

## 🔧 LOADING EXTENSION IN CHROME

### First-Time Setup

1. **Open Chrome Extensions Page**
   - Navigate to: `chrome://extensions/`
   - Or: Menu → Extensions → Manage Extensions

2. **Enable Developer Mode**
   - Toggle "Developer mode" switch (top-right)

3. **Load Unpacked Extension**
   - Click "Load unpacked" button
   - Navigate to project directory
   - Select the `.vite/` folder (**NOT the root folder!**)
   - Click "Select Folder"

4. **Verify Installation**
   - Extension should appear with @NCAD icon and name
   - Check for any errors in the extensions page
   - Click extension icon in toolbar to open popup

### Reloading After Changes

**Every time you make code changes:**
1. Run `npm run build` in terminal
2. Click reload icon (🔄) on extension card in `chrome://extensions/`
3. Test your changes

**Quick Reload Shortcut:**
- Press `Ctrl+R` on `chrome://extensions/` page while extension is selected

## 🐛 TROUBLESHOOTING

### Extension Doesn't Load

**Symptoms:** Extension card shows errors in Chrome
**Solutions:**
1. Check that you selected the `.vite/` folder (not root folder)
2. Verify `manifest.json` exists in `.vite/`
3. Run `npm run build` again
4. Check console for specific errors

### Features Don't Work

**Symptoms:** Toggles don't respond, features don't activate
**Solutions:**
1. Check browser console for errors (`F12` → Console)
2. Verify extension has required permissions
3. Reload extension after making changes
4. Check that content scripts are injected (inspect page, check Sources tab)

### Build Fails

**Symptoms:** `npm run build` shows errors
**Solutions:**
1. Delete `node_modules/` and `.vite/` folders
2. Run `npm install` again
3. Run `npm run build`
4. Check Node.js version compatibility (v18+ required)
5. Check for syntax errors in source files

### Accordion Sections Collapse on Checkbox Click

**Symptoms:** Testing tool sections close when clicking Pass/Fail/Skip
**Solutions:**
- This was fixed in the latest version
- Ensure you have the latest `feature-testing.html`
- Checkboxes now have `event.stopPropagation()`

### Icons Don't Update After Brand Switch

**Symptoms:** Extension shows old icons after running switch command
**Solutions:**
1. Clear Chrome extension cache:
   ```bash
   # Delete .vite/ directory
   rm -rf .vite
   # Rebuild
   npm run switch:ncad
   ```
2. Reload extension in Chrome
3. Hard refresh popup (`Ctrl+Shift+R`)

### Testing Progress Doesn't Transfer

**Symptoms:** Testing checklist is empty on new PC
**Solutions:**
- Export progress before transfer: Click "💾 Export Progress"
- Transfer the `.json` file to new PC
- Import on new PC: Click "📥 Import Progress"
- **Note:** localStorage does NOT transfer with HTML file
