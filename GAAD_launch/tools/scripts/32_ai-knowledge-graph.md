## [DEMO — speak while demonstrating on screen]

"Select a dense passage — a theoretical framework, a case study, a set of definitions — and click 'Knowledge Graph'.

AssisT extracts the key concepts and the relationships between them and renders them as an interactive node graph.

Each node is a concept. Each edge is a relationship — 'causes', 'is a type of', 'contradicts', 'depends on'. You can click any node to see its definition or expand the graph from that point.

This is particularly powerful for visual learners and students with working memory difficulties who find it hard to hold complex relationships in their head while reading linear text.

The graph is zoomable and draggable. You can export it as an image to include in your notes."
