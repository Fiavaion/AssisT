## [DEMO — speak while demonstrating on screen]

"AssisT automatically detects when you're on a Canvas page and activates Canvas-specific enhancements.

On assignment pages, AssisT reformats the brief into a cleaner layout with better visual hierarchy — making it easier to identify what's being asked.

On quiz pages, AssisT can read individual questions aloud as you reach them, so you're not relying solely on reading the text.

On module pages with multiple items, AssisT can highlight the current item and read the page structure aloud — helpful for students using keyboard navigation or screen readers.

AssisT is tested against Canvas LMS specifically. It works on all Instructure-hosted Canvas instances — any URL ending in instructure.com — and on institutionally self-hosted Canvas deployments."
