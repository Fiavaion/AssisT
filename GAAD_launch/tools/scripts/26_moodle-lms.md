## [DEMO — speak while demonstrating on screen]

"When you're on a Moodle course page, AssisT detects the environment automatically and activates Moodle-specific features.

On assignment pages, the brief is reformatted for clearer reading. On forum posts, each reply can be read aloud individually using Read Aloud.

Course page content — lecture notes, resource lists, embedded materials — is all accessible through AssisT's full feature set: Read Aloud, Dictionary, Annotations, AI tools.

To use AssisT on Moodle, you'll need to grant the 'All Sites' permission in the AssisT popup — this allows the extension to run on pages outside Canvas. It's a one-time step.

AssisT has been tested against Moodle 4.x and works across standard Moodle installations."
