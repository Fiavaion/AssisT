**Category: Productivity** | Upload order: 23

## [INTRO — speak during the 5-second chapter animation]

"Simplified Interface removes ads, sidebars, banners, and decorative elements — leaving only the content that matters."

---

## [DEMO — speak while demonstrating on screen]

"Toggle Simplified Interface on from the popup.

AssisT analyses the page and hides non-content elements: advertisements, promotional banners, social media widgets, decorative images, and navigation elements that aren't needed for the current task.

The result is a quieter, less cognitively demanding page. For students with ADHD, autism, or sensory sensitivities, the visual simplification can make a meaningful difference to their ability to focus on the material.

Unlike Reading Mode — which extracts and reflows content — Simplified Interface keeps the page's original layout intact. Links, interactive elements, and media are preserved. Only the noise is removed.

It works on any website."
