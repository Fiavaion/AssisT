"OCR — Optical Character Recognition — extracts text from images, scanned documents, and PDFs, making visual content readable without leaving your browser."

---

## [DEMO — speak while demonstrating on screen]

"When you right-click on any image on a webpage, you'll see an 'Extract text with AssisT OCR' option.

Click it. AssisT analyses the image in your browser and returns the extracted text in a panel on the right side of the screen.

From there you can read it, copy it, or — with one click — send it straight to Read Aloud.

This is especially useful for scanned lecture notes, assignment briefs uploaded as images, or PDFs that weren't created with accessibility in mind.

You can also trigger OCR using the keyboard shortcut. The extracted text is selectable, so all other AssisT features — Dictionary, Translation, AI tools — work on it too.

All processing happens on-device. No image data is uploaded to any server."
