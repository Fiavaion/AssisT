Debug Console Logs

Open the browser console (F12 → Console tab) to see debug information:

  • [AssisT] Settings loaded, TTS enabled: true/false - Shows initial TTS state
  • [AssisT] TTS enabled state changed: false → true - Shows when you toggle TTS
  • [AssisT] Click ignored - TTS is disabled - Shows when clicks are blocked
  • [AssisT] Reading: ... - Shows when text is being read
