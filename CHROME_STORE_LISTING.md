# Chrome Web Store Listing

## Extension Name

@NCAD - Adaptive Accessibility

## Short Description (132 characters max)

Accessibility extension with Text-to-Speech, customizable highlighting, and adaptive features for neurodivergent learners.

## Detailed Description

**@NCAD (Neurodivergent-Centered Adaptive Design)** is a comprehensive accessibility extension designed to support neurodivergent students in their learning journey.

### Key Features

**🔊 Text-to-Speech (TTS)**

- Read any selected text aloud with natural voices
- Synchronized word highlighting for visual tracking
- Adjustable speed, pitch, and voice selection
- Works on any webpage

**✍️ Speech-to-Text (STT)**

- Voice dictation for text input fields
- Support for multiple speech recognition engines
- Confidence feedback and auto-punctuation

**📖 Reading Support**

- Dyslexia-friendly fonts and spacing
- Reading guide/ruler overlay
- Focus mode to reduce distractions
- Bionic reading patterns

**📝 Annotations & Notes**

- Sticky notes on any webpage
- Highlight and annotate text
- Tag and organize notes across pages

**📚 Citation Management**

- Auto-extract citation metadata
- Multiple citation formats (APA, MLA, Harvard)
- Bibliography manager

**🤖 AI-Powered Features**

- Text simplification
- Summarization
- Socratic tutoring
- Assignment breakdown

**🎯 Accessibility First**

- WCAG 2.2 Level AA compliant
- Keyboard navigation throughout
- Screen reader compatible
- Customizable color schemes

### Platform Support

Works on all websites, with enhanced features for:

- Canvas LMS (instructure.com)
- Moodle
- Google Classroom

### Privacy

- No data collection or tracking
- All processing happens locally
- Optional cloud APIs are user-controlled
- FERPA/COPPA compliant

### Permissions Justification

**Why "<all_urls>" access?**
This extension provides accessibility features that users may need on ANY website, not just learning platforms. Features like Text-to-Speech, dyslexia fonts, and reading guides should work everywhere students browse.

**Storage:** Save user preferences and settings locally
**ActiveTab:** Access current tab for accessibility features
**Scripting:** Inject accessibility enhancements into pages
**Downloads:** Export notes and bibliographies
**ContextMenus:** Right-click menu for quick TTS activation
